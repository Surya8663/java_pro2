# 📸 Screenshots Guide

Place the application screenshots in this folder with the following naming convention:

## Required Screenshots

1. **main-menu.png**
   - Shows: Main frame with 4 buttons (Member Login, Register, Admin Login, Exit)

2. **member-dashboard.png**
   - Shows: Member dashboard with 5 action buttons (Browse Books, Borrow a Book, Return a Book, My Borrows, Logout)

3. **browse-books.png**
   - Shows: JTable displaying all available books with columns (ID, Title, Author, Genre, Available Copies)

4. **member-login.png**
   - Shows: Member login frame with Email and Password fields

5. **register.png**
   - Shows: Registration frame with Name, Email, Password fields and Register button

6. **admin-dashboard.png**
   - Shows: Admin dashboard with options (Add Book, View All Books, View All Borrows, Logout)

## How to Add Screenshots

1. Take screenshots of each screen using your preferred tool (Print Screen, Snip & Sketch, etc.)
2. Rename them according to the naming convention above
3. Save them in this `screenshots/` folder
4. Commit and push to GitHub:
   ```bash
   git add screenshots/
   git commit -m "Add application screenshots"
   git push origin main
   ```

## Image Formats

- **Preferred Format**: PNG (lossless)
- **Alternative**: JPG (smaller file size)
- **Recommended Size**: 800x600 or larger for clarity
